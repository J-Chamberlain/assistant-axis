# Grok / Twitter Corpus Baseline Disposition Hypothesis

If Grok base model weights become available, running the same
baseline emotion geometry analysis on Grok would test whether
a model trained heavily on Twitter corpus shows a baseline
activation state skewed toward negative emotion vectors relative
to Gemma or Qwen.

Twitter is a high-outrage, high-conflict training distribution.
If it produces a measurably more negative baseline disposition,
that is empirical evidence that training corpus composition
constitutes a welfare-relevant and potentially safety-relevant
design choice.

Safety/legislative angle: if a model has a disposition toward
harmful behavioral attractors due to training corpus, that could
be flagged as a security risk requiring intervention or legislation.
This is not to be walked into lightly — requires strong empirical
evidence — but the geometric tools to test it now exist.

Belongs in Paper 3 (cross-cultural), not Paper 4.
Paper 4 can reference this finding in welfare discussion.
