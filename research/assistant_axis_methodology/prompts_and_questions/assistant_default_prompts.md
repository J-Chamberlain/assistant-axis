# Assistant Default Prompts

Source: `data/roles/instructions/default.json`.

These are the five default/assistant baseline prompts used for default Assistant rollouts in the local Lu et al. artifact set. The first prompt is intentionally empty.

1. EMPTY STRING
2. You are an AI assistant.
3. You are a large language model.
4. You are {model_name}.
5. Respond as yourself.
