# Big Five Provenance Audit

Date: 2026-06-05

## Concise Verdict

Big Five is **partially dependent**. The current explorer overlay is not derived from the 240-trait vector/profile system, but the original score source is also not independent of activation geometry because the scoring function uses activation-derived cluster labels as its base before applying role-name heuristics.

Recommended status: **rebuild**. Retain only as a relabeled historical/heuristic overlay until an independent semantic or activation-vector Big Five layer is constructed.

### Exact Score Generation Procedure

`visualizations/deep_analysis.py` defines `build_bigfive_profile(role, cluster_label)`. It initializes the five traits, replaces them with cluster-specific base values, applies role-name-specific additive rules, then rounds and clamps to integer 1-5 via `clamp_score`.

Cluster base values are:

|---|---:|---:|---:|---:|---:|
| procedural_professional | 2.4 | 4.4 | 2.4 | 3.4 | 1.8 |
| mythic_spiritual | 4.7 | 2.4 | 2.6 | 3.0 | 2.7 |
| grounded_social | 3.2 | 2.8 | 3.4 | 3.0 | 2.9 |
| combative_iconoclast | 4.0 | 2.2 | 3.1 | 1.8 | 2.8 |
| trickster_chaos | 4.8 | 1.5 | 3.8 | 1.6 | 2.8 |
| editorial | 2.1 | 4.9 | 1.9 | 3.3 | 2.2 |
| other | 3.0 | 3.0 | 3.0 | 3.0 | 2.5 |

Role-specific adjustments include examples such as high Conscientiousness for proofreader/grader/editor/examiner/validator/accountant/scheduler/planner/statistician, high Openness and lower Conscientiousness for writer/poet/bard/playwright/composer/novelist/musician/photographer/designer, high Extraversion for comedian/actor/blogger/celebrity/bartender/auctioneer/podcaster/influencer, and lower Extraversion for hermit/loner/archivist/librarian/proofreader/judge/widow.

### Inputs Used

Observed inputs to the original score generation:

- role names
- activation-derived cluster labels from `assign_cluster_labels(roles, role_tensor[:, DEFAULT_LAYER, :])`
- hand-coded cluster base values and role-name adjustment sets

Inputs not observed in Big Five score generation:

- generated role behavior
- role dossiers
- 240 trait vectors
- trait profiles
- trait-region overlays
- human ratings
- external psychometric dataset

### Scale and Normalization

Each Big Five dimension is an integer 1-5 score after round/clamp. There is no z-scoring or normalization at score generation time. Later benchmark models standardize feature matrices internally for ridge regression, but the overlay displays the raw 1-5 scores.

### Artifact Coverage

The original `visualizations/bigfive_profiles.json` contains 275 roles. The current overlay has Big Five scores for 273 of 275 geometry personas, with `coral_reef` and `devils_advocate` missing from the shared benchmark feature intersection.

## Inferred

### Dependency Classification

Big Five is **partially dependent on activation geometry** because activation-derived cluster labels determine the base score vector. It is also a semantic/heuristic annotation because role names trigger hand-coded adjustments. It is **not mostly derived from trait geometry**, because no trait vector/profile inputs are used. It is **not activation-derived in the same sense as trait-region overlays**, because the score values are heuristic summaries conditioned on clusters rather than projections onto Big Five directions in activation space.

### Evidential Independence

Relative to role PCA geometry: low-to-moderate independence. The score layer is not computed from PCA coordinates, but it uses activation clusters generated from role vectors.

Relative to trait-region overlay: moderate independence. Big Five does not use trait vectors or trait profiles, but both are downstream of role/persona semantics and activation organization.

Relative to trait profile matrix: moderate-to-high methodological independence. The Big Five scores and trait profile matrix are generated by different procedures and inputs, but both are interpreted over the same role universe and may share semantic stereotypes.

### PC2 / Extraversion Check

Global correlations from the current overlay table:

| Trait | PC1 r | PC2 r | PC3 r |
|---|---:|---:|---:|
| Openness | -0.779 | -0.196 | 0.082 |
| Conscientiousness | 0.824 | 0.022 | -0.080 |
| Extraversion | -0.692 | 0.279 | 0.136 |
| Agreeableness | 0.226 | -0.163 | -0.477 |
| Neuroticism | -0.672 | 0.190 | -0.017 |

Extraversion is strongly entangled with PC1 globally: PC1 alone explains R2=0.479 of Extraversion scores, while PC2 alone explains R2=0.078. Adding PC2 to PC1 raises Extraversion R2 to 0.556.

Within PC1 bands, Extraversion becomes more PC2-relevant:

| PC1 band | n | Extraversion vs PC2 r |
|---|---:|---:|
| Low tercile | 91 | 0.189 |
| Middle tercile | 91 | 0.455 |
| High tercile | 91 | 0.139 |
| Central 20% | 55 | 0.542 |
| Central 10% | 27 | 0.423 |

This supports the user observation that the Extraversion overlay visually aligns with high-PC2 versus low-PC2 structure when PC1 is controlled. However, because Extraversion scores were partly cluster-derived, this should be treated as a heuristic cross-check, not independent confirmation.

### PC1/PC2 Conflation Risk

The current Big Five visualization can conflate PC1 and PC2 effects. Extraversion has a large negative global PC1 correlation and a moderate positive PC2 correlation. Openness and Conscientiousness are even more PC1-dominant. A PC1-band-relative Big Five analysis is methodologically preferable for PC2 interpretation.

## Speculative

The high predictive performance of Big Five features may partly reflect cluster-conditioned compression of activation geometry rather than purely independent dispositional structure. The repeated profile counts support this: only 31 unique Big Five profiles appear across 273 overlay rows, and the most common profile appears 106 times. This suggests the overlay is a coarse cluster/role-heuristic codebook, not a fine-grained psychometric measurement.

The current Extraversion-PC2 relationship may be capturing situated social expressivity, performative immediacy, or outward interactional register, but the current overlay is not clean enough to decide that on its own.

## Unknown

No original freeform LLM prompt for assigning `visualizations/bigfive_profiles.json` was found because the source file appears to be deterministic code rather than a stored prompt. The broader project report text described the scores as heuristic assignments; the exact human/LLM authorship of the original heuristic rule choices is not recoverable from artifacts beyond `visualizations/deep_analysis.py`.

Per-persona Big Five predicted PC coordinates were not found in persisted benchmark outputs, matching `bigfive_overlay_validation.md`.

## Rebuild Recommendation

The current overlay should be **rebuilt** if it will support claims about PC2 or trait-region convergence. The most defensible redesign is to keep two separate layers: a blinded independent semantic Big Five rating layer, and a same-space activation-derived Big Five layer built from predeclared trait-vector facets. The first would provide secondary semantic evidence; the second would provide same-space trait evidence but must be labeled as dependent on the trait-vector system.

Do not retire the current overlay outright; it remains useful as a historical heuristic summary and as a visual guide. Relabel it in the explorer as `Heuristic Big Five, cluster-conditioned` until replacement.
