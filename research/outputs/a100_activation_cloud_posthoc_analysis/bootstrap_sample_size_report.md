# Bootstrap Sample-Size Report

Bootstrap estimates use all-response, pre-filter clouds. Judge filtering can reduce retained n and increase raw-generation requirements.

## amateur

- First n with median centroid error < 5: 20
- First n with 90th percentile centroid error < 10: 15
- First n with all axis-wise SE < 5: 15
- Practical recommendation: use at least 20 retained responses for stable unfiltered centroid estimates under these criteria.

## playwright

- First n with median centroid error < 5: 30
- First n with 90th percentile centroid error < 10: 30
- First n with all axis-wise SE < 5: 30
- Practical recommendation: use at least 30 retained responses for stable unfiltered centroid estimates under these criteria.
