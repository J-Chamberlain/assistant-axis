# Instructions for Independent External Review of the Frozen SAPA Packet

Use `sapa_category3_external_review_packet.csv` with version 1.0 of `sapa_category3_review_rubric.md`.

Review each row using only the canonical model-trait definition, exact SAPA item wording, source-scale metadata, response anchors, and documented reverse-key information supplied in the packet. Do not inspect persona names, PC coordinates, model-geometry results, predictor coefficients, trait ranks, sparsity analyses, occupation or NLSY97 outcomes, the original feasibility category, the Codex second-pass decisions, or any downstream correspondence result.

Return one of `ACCEPT_DIRECT`, `ACCEPT_CLOSE`, `DOWNGRADE_BROAD`, `REJECT`, or `AMBIGUOUS` for every `review_id`, plus all rationale and evidence fields required by the frozen rubric. Do not alter the rubric after reviewing aggregate counts; if a rubric revision is necessary, version it and rerun all 78 rows.

The purpose is blinded semantic adjudication for a provisional measurement crosswalk. It is not a request to judge model-PC usefulness, and an accepted link is not by itself proof of psychometric equivalence. Record the reviewer's identity or system, review date, conflicts of interest, and whether any prohibited information was visible.
